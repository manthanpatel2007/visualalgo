## 📌 Project Overview

Algorithm Arena is an educational frontend project designed to make data-structure algorithms easier to understand visually.

Instead of only reading the algorithm code, users can:

- Select a sorting or searching algorithm
- Generate a random array
- Watch the algorithm execute step by step
- Pause and resume the visualization
- Change the array size
- Control the animation speed
- See comparisons, pivots, sorted elements, and found elements
- View algorithm complexity and additional information

The entire project runs in the browser and does **not require a backend or database**.

## ✨ Features

### 🔢 Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

### 🔍 Searching Algorithms

- Linear Search
- Binary Search

### 🎮 Visualization Controls

- ▶️ Play an algorithm
- ⏸️ Pause the visualization
- ▶️ Resume the visualization
- 🔄 Generate a new random array
- 📏 Change array size
- ⚡ Change animation speed

### 📊 Algorithm Information

For each algorithm, the application displays:

- Algorithm name
- Description
- Time complexity
- Space complexity
- Best-case complexity
- Average-case complexity
- Worst-case complexity
- Stability information
- How the algorithm works

### 🎨 Visual States

Different colors represent algorithm states:

| State | Meaning |
|---|---|
| 🔵 Unsorted | Normal array element |
| 🟡 Comparing | Elements currently being compared |
| 🟠 Pivot / Key | Pivot or key element |
| 🟢 Sorted | Element already placed correctly |
| 🟣 Found | Target element found |
| ⚪ Discarded | Elements no longer considered |
